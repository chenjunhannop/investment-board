# 自选列表文件夹分类设计文档（同花顺式）

- 日期：2026-08-18
- 状态：设计已获用户认可（Part 1-3 分节确认）
- 背景：当前自选为扁平列表（`[{code,name}]`），需升级为同花顺式文件夹分类，并预置持仓 + 各领域龙头

## 1. 目标

1. 自选列表支持**文件夹（分组）分类**：同花顺式，一个文件夹代表一个领域，可新建/重命名/删除/展开折叠
2. 预置 **1 个"持仓"文件夹（6 只）+ 15 个领域文件夹（每领域 7 只龙头）**，共 16 文件夹 111 只股票
3. 持仓与自选分离（持仓独立文件夹），行情/新闻服务遍历所有文件夹拉取

## 2. 非目标（明确不做）

- 不做文件夹嵌套（只一层分类）
- 不做跨文件夹移动股票（YAGNI，可后续加）
- 不做"删除文件夹时股票移入未分组"（删除即连带删除，语义明确）
- 不改行情/新闻链路（仅 `_collect_codes` 遍历所有文件夹）
- 不改项目目录结构；只读红线不变

## 3. 数据结构（watchlist.json v2）

```json
{
  "version": 2,
  "groups": [
    { "name": "持仓",  "stocks": [{ "code": "600900", "name": "" }, ...] },
    { "name": "银行",  "stocks": [...] },
    { "name": "白酒",  "stocks": [...] },
    ... 共 16 个文件夹
  ]
}
```

**兼容迁移**：v1 扁平 `[{code,name}]` → v2，自动迁移为 `{"version":2,"groups":[{"name":"未分组","stocks":原数组}]}`（不丢失已有自选）。

## 4. API

| 方法 | 路径 | 请求 | 响应 | 校验 |
|---|---|---|---|---|
| GET | `/api/watchlist` | — | `{groups:[{name,stocks}]}` | — |
| POST | `/api/watchlist/groups` | `{name}` | 更新后结构 | 名称非空/唯一，重名 400 |
| PUT | `/api/watchlist/groups/{name}` | `{new_name}` | 更新后结构 | 新名非空/唯一 |
| DELETE | `/api/watchlist/groups/{name}` | — | 更新后结构 | 文件夹不存在 404 |
| POST | `/api/watchlist/stocks` | `{group, code}` | 更新后结构 | 6 位数字；文件夹存在；代码去重 |
| DELETE | `/api/watchlist/stocks/{group}/{code}` | — | 更新后结构 | 文件夹/股票不存在 404 |

- 删除文件夹 = 删除其中全部股票（不迁移）
- 名称补齐沿用现有机制：预置/添加仅存 `code`（name 空），显示层用行情 `Quote.name` 补齐

## 5. 前端交互

- **文件夹区块**：标题栏（▾ 折叠箭头 + 名称 + 股票数 + 重命名/删除按钮）+ 内部行情卡片 grid（复用 PriceCard，实时更新）；默认展开，点击标题切换
- **添加股票**：页面顶部统一添加栏（输入 6 位代码 + 下拉选择目标文件夹 → 添加）
- **新建文件夹**：输入名称创建空文件夹
- **store**：`watchlist` 状态改为 `{groups: [{name, stocks}]}`；操作 `addGroup/renameGroup/removeGroup/addToWatchlist/removeFromWatchlist`
- 持仓文件夹预置排第一，普通可管理（不强制特殊）

## 7. 约束与合规

- **只读红线**：不得引入 buy/sell/trade/order 前缀标识符或中文交易业务词；`make check` 必须 OK
- **兼容**：既有 v1 watchlist.json 迁移不丢数据；既有自选测试升级为分组结构
- **工具链**：ruff/yapf/mypy/eslint/prettier 全绿；`make test` 既有 + 新增分组用例全绿；`make build` 成功
- **命令**：一律 `backend/.venv/bin/`；前端 `cd frontend && npm run ...`
- 新代码 Google docstring；commit 用 `feat:`（分类功能）与 `chore:`（数据预置）

## 8. 验收标准

1. `make check/lint/typecheck/test/build` 全绿（含新增分组存储/API/前端测试）
2. 自选页显示 16 个文件夹（持仓 + 15 领域），每领域 7 只龙头，行情实时显示
3. 文件夹可新建/重命名/删除/展开折叠；添加股票可选目标文件夹；删除文件夹连带删除
4. 所有预置代码能拉到行情（代码有效性验证通过）
5. 旧 v1 watchlist.json 迁移后数据不丢失
6. 行情/新闻服务按所有文件夹代码拉取
