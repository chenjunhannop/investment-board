# 股票看板（Investment Board）设计文档

> 日期：2026-08-18
> 状态：已评审
> 项目仓库：git@github.com:chenjunhannop/investment-board.git

## 1. 项目目标

一个**开源、个人自托管**的股票看板：连接用户的同花顺账号，对用户账号内的**自选股**、**持仓股**进行实时趋势观察，并推送与持仓/自选相关的**个股新闻**与**全局市场快讯**。

**两个核心设计亮点：**

1. **账号隐私** —— 凭据只在用户本机加密存储，所有数据不出用户机器，不上传任何云端。
2. **数据获取合规性** —— 同花顺账号接口只读（代码层面无交易能力）、低打扰限频、新闻行情走公开数据源、透明免责声明。

## 2. 关键决策记录

| 决策点 | 选择 |
|---|---|
| 使用形态 | 开源项目，每个用户个人自托管、登录自己的账号 |
| 数据获取方式 | 方案 2：自研轻量只读客户端（模拟同花顺网页版/H5 登录，只封装查询接口） |
| 运行形态 | 本地 Web 面板（本地服务 + 浏览器访问） |
| 市场范围 | 纯 A 股（架构保留市场扩展维度） |
| 新闻数据源 | 全部走公开财经源（东财公告 / 财联社电报） |
| 前端技术栈 | React（Vite）+ ECharts |
| 后端技术栈 | Python + FastAPI + WebSocket |

## 3. 总体架构

```
┌──────────────────────────────────────────────────────┐

└──────────────────────┬───────────────────────────────┘

┌──────────────────────▼───────────────────────────────┐
│             后端  FastAPI (仅监听 127.0.0.1)            │
│                                                       │
│  ┌─────────────┐  ┌───────────┐  ┌──────────────┐    │
│  │ THS只读客户端 │  │ 行情采集器  │  │ 新闻采集器     │    │
│  │ (自选/持仓,   │  │(新浪/腾讯,  │  │(东财公告/     │    │
│  │  可插拔)     │  │  含分时)    │  │ 财联社电报)   │    │
│  └──────┬──────┘  └─────┬─────┘  └──────┬───────┘    │
│         └───────────────┴────────────────┘            │
│                       │                              │
│  ┌────────────────────▼─────────────────────────────┐ │
│  │            调度器 asyncio 任务                     │ │
│  │   行情 3s轮询 │ 持仓 10s │ 新闻 60s │ 会话保活     │ │
```

### 核心原则

- **模块化**：`ths_client` / `market` / `news` / `core`（调度）/ `vault`（凭据）/ `api` / `web` 各自独立，通过清晰接口通信，可单独测试。
- **单向数据流**：采集器 → 调度器 → WebSocket → 浏览器；前端不直接碰任何数据源。
- **降级容错**：行情/新闻走公开源，即使 THS 接口失效，看板行情和新闻依旧可用，仅"自选/持仓"变灰并提示。

## 4. 数据层设计

### 4.1 数据来源划分（最小化账号暴露面）

| 数据 | 来源 | 说明 |
|---|---|---|
| 自选列表 | THS 只读接口 | 账户专属数据 |
| 持仓明细（成本/数量） | THS 只读接口 | 账户专属数据 |
| 实时价格/涨跌幅/分时 | 公开行情源（新浪/腾讯免登录） | 非账户专属 |
| 个股新闻 + 全局快讯 | 公开新闻源（东财/财联社） | 免登录 |

THS 接口只做两件事：**登录拿会话 + 读自选/持仓列表**。行情和分时都不经过 THS。

### 4.2 THS 只读客户端（`ths_client`）

- 抽象基类 `ThsAdapter`：`query_watchlist()` / `query_positions()` / `refresh_session()`；实现类 `ThsWebClient` 逆向同花顺网页版/H5 接口。
- **扫码登录**：手机同花顺 App 扫码 → 拿 token + 会话 cookie → 存入 vault。
- 会话保活任务：定期检查过期，过期则提示重新扫码；只读轮询不触发风控。
- 接口失效时：该模块单独崩，行情/新闻不受影响，日志给出可读错误提示，社区可提 PR 修。

### 4.3 行情采集器（`market`）

- 适配新浪 `hq.sinajs.cn` + 腾讯 `qt.gtimg.cn`（互为备份）。
- 自选 + 持仓代码去重合并后统一轮询（3s），同时拉当日分时。
- 统一输出标准模型，后续加行情源只需新增适配器。

### 4.4 新闻采集器（`news`）

- 个股新闻：东财个股公告接口按代码拉取，匹配自选/持仓。
- 全局快讯：财联社电报接口（免登录公开）。
- 60s 增量轮询，标题/URL 去重，前端可标记已读；条目标注来源归属。

### 4.5 核心数据模型

- `Stock`：代码 / 名称 / 市场
- `Position`：代码 / 名称 / 数量 / 成本价 / 市值 / 盈亏 / 盈亏比例
- `NewsItem`：来源 / 标题 / URL / 时间 / 关联代码 / 类型（individual / global）

## 5. 合规与隐私设计（核心亮点）

以"**代码级强制、而非靠自觉**"为原则：

1. **只读边界** —— THS 客户端根本没有 `place_order()` / `buy()` / `sell()` 之类方法，只有查询方法；CI 静态检查禁止引入任何含下单语义的依赖/调用（黑名单扫描）。
2. **本地闭环** —— 后端只绑定 `127.0.0.1`，无遥测、无上报、无第三方 SDK；数据只存在于本机内存 + 本地加密库。
3. **凭据保险箱（vault）** —— token/会话凭证 AES-256-GCM 加密存本地 SQLite；密钥存系统 Keychain（macOS / Windows / Linux Secret Service），密钥永不进代码、永不落盘明文；会话过期自动提示重登，支持多账户按配置文件隔离。
4. **一键清除** —— 设置页"注销并清除全部本地数据"：删除会话、清空缓存、移除加密记录。
5. **低打扰访问** —— 全部请求限频：THS 接口 ≥10s 间隔 + 随机抖动；公开行情 3s；新闻 60s；请求头模拟正常浏览器但绝不伪装他人或绕过验证码。
6. **透明合规声明** —— README + LICENSE：仅供个人学习研究、不构成投资建议；数据版权归同花顺及各数据源所有；访问频率受控；账号风险用户自担；行情/新闻界面标注数据来源归属。

## 6. 后端与前端

### 6.1 后端（`api` + `core`）

- FastAPI 绑定 `127.0.0.1`，默认端口 8210，仅本机访问。
- REST：登录状态查询、手动刷新、新闻已读、注销清除。
- WebSocket 单通道：采集器 → 事件总线 → 广播，前端按事件类型分发渲染。
- 调度器（asyncio）：行情 3s / 持仓 10s / 新闻 60s / 会话保活。

### 6.2 前端（`web`）

- React + Vite + ECharts，深色主题。
- 四个视图：
  - **看板**：自选实时行情列表（价格/涨跌幅/迷你分时 sparkline）+ 持仓盈亏卡片
  - **持仓**：明细表（成本/现价/市值/盈亏/当日盈亏）
  - **新闻**：全局快讯流 + 个股新闻（按自选/持仓筛选），可标记已读
  - **设置**：扫码登录入口、注销清除、数据源健康状态（THS/行情/新闻）
- WebSocket 客户端：断线自动重连 + 连接状态指示。

## 7. 错误处理

- **分层降级**：THS 失效 → 行情/新闻照常，界面提示"自选/持仓暂不可用"。
- **行情源切换**：行情源 A 挂 → 自动切备份源 B。
- **限频与退避**：429/风控 → 指数退避重试 + 日志；所有外部调用设超时与重试上限。
- **健康灯**：前端展示各数据源健康状态。

## 8. 测试

- **单元测试**：数据模型、去重合并、盈亏计算、新闻去重、vault 加解密。
- **适配器解析测试**：用录制的 mock fixture 测 THS/行情/新闻解析（不依赖真实账号与网络）。
- **CI**：静态检查（含下单黑名单扫描）+ pytest + 前端 build。

## 10. MVP 范围

**做**：自选实时行情 + 分时、持仓盈亏、新闻（个股 + 全局）、扫码登录/注销、数据源健康。

**不做（架构留扩展点，后续可加）**：K 线、资产历史曲线、价格提醒、多市场、移动端。
