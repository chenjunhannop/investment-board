# 看板大屏视觉重做设计文档（DataV 规范）

- 日期：2026-08-18
- 状态：设计已获用户认可
- 背景：上一版看板大屏被用户指出"是放大的网页 dashboard，不是真正的数据大屏"。本 spec 基于对**数据大屏（DataV/AntV/ECharts 大屏）设计规范的调研**，视觉层彻底重做；数据层（`/api/dashboard` 聚合快照）已就绪，保留不变。

## 1. 调研结论（数据大屏设计规范）

业界公认的大屏（Big Screen / 指挥大屏 / DataV）设计要素：

1. **深色渐变大屏背景**：非纯色，带渐变 + 网格纹理 + 光晕，沉浸式
2. **模块发光边框 + 四角装饰角标**：大屏标志性元素
3. **顶部大标题区**：居中大标题 + 左右/右侧时间日期
4. **对称三分区布局**：左中右对称，主视觉居中，一屏展示（16:9，尽量无滚动）
5. **超大等宽数字**：核心指标 36-48px 等宽数字（tabular-nums），数字是大屏灵魂
6. **大屏动效**：数字跳动（countup）、数据轮播/滚动、脉冲呼吸、边框扫描线；尊重 reduced-motion
7. **信息层级**：标题 > 指标值 > 标签 > 辅助

## 2. 目标

按上述规范重做 Dashboard 大屏的**视觉层**：深色渐变背景、发光边框角标、顶部大标题、超大等宽数字、动效、对称三分区布局。数据来源/接口不变。

## 3. 非目标（明确不做）

- 不改后端：`/api/dashboard`、`sector.py`、`dashboard.py` 全部保留
- 不改 7 个数据模块的内容与数据源
- 不做地图/粒子等无关装饰（金融大屏克制）
- 不改自选/新闻/设置页（仅 Dashboard 大屏视觉）
- 不做独立全屏模式（保留导航，大屏页全宽）

## 4. 视觉规范（设计 Token）

### 4.1 背景
```
--bs-bg: linear-gradient(180deg, #0a1128 0%, #0d1520 60%, #0b1220 100%)
+ 背景网格线（linear-gradient 细线纹理，1px rgba(255,255,255,0.03)）
+ 顶部光晕（radial-gradient rgba(212,169,72,0.08)）
```
应用在 Dashboard 大屏容器，不再用纯色 body。

### 4.2 模块发光边框 + 角标
- 模块容器：`background: rgba(19,26,35,0.6)` + `border: 1px solid rgba(76,120,255,0.18)`（科技蓝调）+ 内阴影微光
- **四角角标**：每个模块四角各一个 L 形发光角标（CSS 伪元素 `::before/::after` + 额外元素或 clip-path），色 `rgba(212,169,72,0.6)`（琥珀金，与项目 accent 一致）
- 模块标题：左侧 3px 琥珀金竖条 + 渐变下划线（`linear-gradient(90deg, accent, transparent)`）

### 4.3 顶部大标题区
- 居中大标题"市场数据中心"（26px 粗体 + 字距 + 底部渐变光效线）
- 右侧/左右时间（等宽数字 14px，`2026-08-18 19:30:00`，秒级更新）
- 标题下方分隔线渐变

### 4.4 超大等宽数字
- 指数点位：`font-family: var(--font-data)` + 40px + tabular-nums，红涨绿跌
- 涨跌家数：36px 数字对比（红 ↑ / 绿 ↓）
- 涨跌幅：18px 带符号
- 排行/资金/新闻：等宽数字，tabular-nums

### 4.5 动效
- **数字跳动**：指数/指标值变化时过渡动画（新 hook `useCountUp`：值变化时数字滚动/淡入，300ms）
- **数据轮播**：底部自选/新闻自动滚动（CSS animation 或 JS interval，8s 轮播/滚动）
- **脉冲呼吸**：状态点/模块标题（2.4s 循环）
- **涨跌过渡**：颜色变化 200ms
- 全部包裹 `@media (prefers-reduced-motion: reduce)` 关闭

## 5. 布局（对称三分区）

```
┌──────────────────────────────────────────────────────────┐
│ 【 市场数据中心 】                  2026-08-18 19:30:00   │
├──────────────────────────────────────────────────────────┤
│  上证 3920 -1.8% │ 深证 14085 -3.7% │ 创业板 3533 -4.6%  │  ← 大数字卡
│  涨跌家数：↑646  ↓1081（比例条）                           │  ← 市场温度
├───────────┬────────────────────────────┬─────────────────┤
│ 板块涨幅榜  │  重点板块走势（主视觉）      │  板块资金流向     │
│ 炼油 +6%  │  ┌──┐ ┌──┐ ┌──┐            │  主力净流入 TOP   │
│ 煤炭 +5%  │  │K │ │K │ │K │ 涨幅前三     │  （横向条形图）   │
│ ...       │  └──┘ └──┘ └──┘            │                 │
│ 板块跌幅榜  │  ┌──┐ ┌──┐ ┌──┐           │                 │
│ ...       │  │K │ │K │ │K │ 跌幅前三     │                 │
├───────────┴────────────────────────────┴─────────────────┤
│ 自选行情（自动滚动）              │  新闻快讯（轮播）        │
└──────────────────────────────────────────────────────────┘
```

- 左列：板块涨幅榜 + 跌幅榜（含领涨/领跌股）
- 中列（主视觉）：涨幅前三 + 跌幅前三板块 K线图（6 块，融入大屏边框角标）
- 右列：板块资金流向（横向条形图）
- 底部：自选横排滚动 + 新闻轮播
- 顶部：指数大数字卡 + 市场温度条
