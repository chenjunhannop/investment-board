# 产品愿景：AI 助手（未来方向）

> 本文记录项目的长期愿景：把 **AI 助手**融入 Investment Board，让看板从「被动展示数据」升级为「主动决策辅助」。当前不实现，仅作为未来设计的输入。

## 核心理念

Investment Board 目前是**数据展示层**（大屏 / 自选 / 新闻 / 设置），数据基础已完整。
愿景是在其上叠加 **AI 决策层**：AI 读取项目数据，主动给出选股建议、动态调整看板与行业股票，让看板成为「会思考的投资终端」。

## AI 能力方向

| 能力 | 描述 | 所需数据（已就绪） |
|---|---|---|
| **数据驱动选股** | AI 基于行情、板块、资金流、K 线、新闻等综合数据，给出选股/回避建议 | `/api/dashboard`（指数/板块/资金/家数）、`/api/quotes`（自选行情）、`/api/news` |
| **自动调整看板** | AI 根据市场热点动态调整大屏重点板块（涨幅/跌幅前三由 AI 加权筛选而非纯排行） | `/api/dashboard` 板块数据 |
| **动态行业股票** | AI 维护/优化行业板块与龙头股清单（随行情变化推荐增删，写回本地自选） | `/api/watchlist`（文件夹分类增删查） |
| **持仓分析** | AI 基于持仓 6 只 + 市场数据，给出盈亏归因、风险提示、操作参考（仅建议，不自动交易） | `/api/quotes` + 自选「持仓」文件夹 |
| **新闻解读** | AI 摘要个股公告、识别影响板块/个股的事件 | `/api/news` |

## 现有数据基础（AI 输入源，全部就绪）

- **指数**：上证 / 深证 / 创业板（新浪）+ 真实日 K（腾讯）
- **板块**：行业板块涨跌排行、主力资金流、涨跌家数、领涨股（东财）
- **K 线**：指数 / 板块领涨股日 K（腾讯）
- **行情**：自选 / 持仓实时行情（新浪 / 腾讯）
- **新闻**：个股公告 + 全局快讯（东财）
- **自选**：本地文件夹分类（持仓 + 15 领域龙头，增删查 API）

## 集成方式（未来）

- **AI 助手调用项目 API**：通过 pi / Claude 等 AI 助手读取项目数据（`/api/dashboard` 等）进行推理，再通过写 API（`/api/watchlist` 增删）落地调整——无需改造项目内部，符合「本地自托管 + 隐私」定位。
- **内置 AI 服务**（可选演进）：项目内嵌 AI 分析接口，前端直接消费建议。

## 约束（延续项目红线）

- AI 仅提供**建议**，**不做任何自动交易**（延续只读红线，`make check` 拦截交易语义）。
- 数据不出本机；AI 调用（若走外部模型）需用户知情并可控。
- 一切调整写回本地自选（用户可查看 / 回滚）。

## 演进路径（未来里程碑）

1. **阶段 1 · 辅助分析**：AI 读取现有数据，输出选股 / 板块 / 持仓分析建议（只读）。
2. **阶段 2 · 半自动调整**：AI 给出「增删自选 / 调整看板」建议，用户一键应用（经 `/api/watchlist` 写回）。
3. **阶段 3 · 自动维护**：AI 周期分析市场，自动维护行业龙头清单（用户可配置开关）。

> 当前状态：数据层完成（MVP + 大屏 + 自选文件夹 + Docker 部署），AI 层待未来按此愿景设计。
